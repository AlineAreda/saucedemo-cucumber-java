# 💻Saucedmo - Projeto de Automação Web

Este projeto é uma suíte de testes automatizados para a aplicação web **SauceDemo**. O projeto utiliza Selenium para automação de navegadores e Cucumber para a definição e execução de testes baseados em BDD (Behavior Driven Development).


# 👨🏻‍💻Tecnologias Utilizadas

-   **Java**: Linguagem de programação principal.
-   **Maven**: Ferramenta de gerenciamento de dependências e build.
-   **Selenium 3.141.59**: Biblioteca para automação de navegadores.
-   **WebDriverManager 5.0.3**: Gerenciamento automático de drivers para Selenium.
-   **Cucumber 6.9.1**: Framework para BDD, usado para escrever cenários de teste em linguagem natural.

 
## 🤖 Configuração e Execução
1. Clone o repositório para sua máquina local:

```bash
git clone https://github.com/seu-usuario/saucedmo.git
cd saucedmo
```

### Instalar Dependências
2. Instale as dependências do projeto usando Maven:
```bash
mvn clean install
```

### Executar os Testes

3. Execute os testes usando o Maven. Os testes serão executados com o Cucumber, utilizando as definições de passos e cenários de teste definidos nos arquivos `.feature`.

```bash
mvn test
```
